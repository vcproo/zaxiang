AGENT · 智能体

Agent：从"出主意"到"去办事"

这两年 AI 圈最热的词，可能就是 Agent 了，中文常叫"智能体"。说白了就一件事：AI 不光会说，还开始会做了。

军师和跑腿的

你问普通的聊天 AI："周六晚上想带爸妈吃顿饭，帮我订个餐厅。"

它会很热心地告诉你：可以考虑离家近的、口味清淡的、有包间的，订之前记得打电话确认……说得都对，但最后还得你自己去订。它是个军师，只出主意。

Agent 不一样。同样一句话交给它，它会自己去查附近的餐厅、看评价、看有没有空位，然后真的帮你把位子订上。它是个能跑腿的。

它是怎么干活的

Agent 干活的套路，跟人办事差不多，就是一个圈，反复转：

一直转，直到事情办完，或者遇到需要问你的地方

关键在"看结果"这一步。事情不总是一次就成的，订不上就换一家，查不到就换个关键词。普通的聊天 AI 说完一段话就停了，Agent 会根据结果自己调整下一步。

下面一步一步看它怎么订这顿饭：

动手试试：看 Agent 订餐厅
周六晚上 6 点，带我爸妈吃饭，一共 3 个人，离家近点，我爸不吃辣。

注意第 7 步：付钱之前，它停下来问了你。靠谱的 Agent 都应该这样，花钱、发消息、删东西这类收不回来的事，要先问人。

它凭什么能"动手"？

AI 本身只会处理文字，它没有手。能动手，是因为有人给它接上了各种"工具"：能搜索网页的、能打开 App 的、能读写文件的、能发邮件的。

AI 负责动脑子，判断该用哪个工具、怎么用；工具负责真正去执行。这就像一个聪明的经理，手下配了一群干具体活的人。

怎么给 AI 接工具？这就要说到下一篇的 MCP 了。

现在都能见到哪些 Agent

  • 手机上：一些手机助手已经能帮你点外卖、打车、回消息，你说一句，它在各个 App 之间点来点去。
  • 写程序：程序员用的编程 Agent，能自己读代码、改代码、跑测试，出了错再修。这是目前 Agent 用得最成熟的地方。
  • 查资料："深度研究"类的功能，它会自己搜几十个网页，读完再整理成一份报告给你。
  • 办公：帮你整理表格、写周报、把一堆文件归类。

还没那么神

说实话，Agent 现在还处在"能用，但得盯着"的阶段：

  • 步骤一多，中间哪一步理解偏了，后面就一路错下去。
  • 它可能会很"自信"地办错事，比如订错日期。
  • 你给它的权限越大，出错的代价越大。

所以现阶段的正确用法是：让它干，但你来把关。小事放手，大事过目。

记住这一句

聊天 AI 是出主意的军师，Agent 是能跑腿的助手。它会自己想、自己做、看结果再调整，但关键的事得你点头。
