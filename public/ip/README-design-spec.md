# 蜘蛛侦探 IP 设计规范

版本：v1.0 · 2026-10-12  
角色名称：待定（本文使用“蜘蛛侦探”作为工作名称）  
适用范围：角色插画、品牌物料、表情贴纸、动画及立体开发的设计依据。

![标准三视图、表情与道具](./IP标准设定图.png)

## 1. 角色定位

角色是一位安静、敏锐、做事认真的小侦探，拥有蜘蛛的感知特征。性格关键词：严肃、克制、好奇、可靠。可爱感来自大头短身和圆润轮廓；严肃感来自低垂眼睑和微小嘴形，不靠凶狠眉毛或攻击性动作。

一句话设定：总能察觉被别人忽略的小线索。

## 2. 核心识别与不可变项

1. 奶白色兜帽包裹深色脸部，帽顶两侧为短而圆钝的折角，不延长成动物耳朵。
2. 两只薄荷绿主眼上方各有三颗小副眼，共八只眼睛。副眼采用固定实色或统一简洁高光，不增加其他额头装饰。
3. 兜帽正面上方仅放置一个深色蜘蛛标记：头胸部与腹部两枚相连圆形，加八条简化腿线。标记属于印花，不是实体肢体。
4. 素色墨紫短斗篷、圆形浅色领扣、两只短手和两只短脚。
5. 蜘蛛识别只集中在“副眼”和“帽顶标记”两处。禁止添加大面积蛛网、实体蜘蛛腿、线轴和装饰丝线。

## 3. 标准三视图

视觉示意见同目录《IP标准设定图.png》。本节尺寸与数量规定是后续矢量定稿的依据；生成图如存在局部差异，以文字规范为准。

| 视角 | 标准要求 |
| --- | --- |
| 正面 | 站姿端正，两脚着地；头、领扣与躯干共用垂直中轴；两组副眼对称；正面展示帽顶标记。 |
| 左侧面 | 朝左，接近正交投影；只显示近侧可见眼睛；兜帽后脑圆润，面部内凹；斗篷前后厚度克制，不增加尾巴或腹囊。 |
| 背面 | 与正面同高同宽；帽面和斗篷均为纯色；不复制蜘蛛标记，不出现眼睛；仅允许必要的中缝与体积阴影。 |

三视图使用同一头顶线、下巴线、领扣线、斗篷下缘线和脚底线。采用自然垂手、不持道具的中性姿势，避免道具遮挡身体结构。动作插画可以透视变化，标准三视图不可使用明显透视缩短。

## 4. 比例基准

设站立全高为 H＝100 单位，包含帽顶与脚底，不包含道具。以下为本版建议锁定的绘制基准，不是对生成图片的像素测量。

| 部位 | 基准 |
| --- | --- |
| 头部及兜帽高度 | 60H%，约为全身的 3/5 |
| 兜帽最大宽度 | 68H%，正面左右对称 |
| 肩颈连接位置 | 距头顶约 58H%，用兜帽下缘遮住连接 |
| 斗篷下缘 | 距头顶约 88H% |
| 斗篷最大宽度 | 56H%，小于兜帽宽度 |
| 脚部可见高度 | 12H%，短圆，不画明显脚趾 |
| 单只手部 | 长约 12H%、宽约 8H%，圆手套形 |
| 面部开口 | 宽约 46H%、高约 36H%，居中嵌入兜帽 |
| 单只主眼外形 | 宽约 15H%、高约 11H%；常态眼睑遮挡上部 |
| 单颗副眼 | 直径约 2H%，同组中心间距约 4H% |
| 帽顶蜘蛛标记 | 外接框宽约 10H%、高约 8H% |
| 领扣 | 直径约 4H% |

副眼两组沿主眼上方略微倾斜排列，彼此独立，不与主眼或兜帽边缘相切。常态两眼视线聚焦一致。斗篷下缘采用宽缓圆弧，避免蝙蝠翅膀式尖锐锯齿。

## 5. 标准色

数字物料统一使用 sRGB。下列色值是后续制作的标准目标；概念图中的光影颜色不作为取色依据。

| 色名 | HEX | RGB | 用途 |
| --- | --- | --- | --- |
| 蛛丝奶白 | #F3EBDD | 243, 235, 221 | 兜帽、领扣、笔记本纸页 |
| 深墨黑紫 | #27232D | 39, 35, 45 | 脸、手、脚、蜘蛛标记、主体轮廓 |
| 斗篷墨紫 | #49414F | 73, 65, 79 | 斗篷、笔记本封面 |
| 感知薄荷绿 | #C7EFDC | 199, 239, 220 | 主眼、副眼、放大镜镜片 |
| 证物朱红 | #D95A49 | 217, 90, 73 | 小型证物标签，整个人物面积不超过 3% |

优先使用平涂，最多增加一层轻阴影。不要引入大面积渐变、金属反射和高光颗粒。印刷时按承印材料、印厂 ICC 配置转换并打样，不将自动转换的 CMYK 数值视作通用标准。

## 6. 线条与画面风格

采用简洁二维轮廓。标准尺寸下外轮廓线宽约 0.6H%，内线约 0.3H%，端点与转角圆润。主体缩小时可适当增粗，优先保证副眼分离、蜘蛛标记可识别。

兜帽保留必要的包裹褶皱；斗篷正面最多两条轻微结构褶线，背面最多一条中缝。禁止用密集纹理填满纯色区域。不要写实毛发、布料颗粒或复杂材质噪声。

## 7. 表情规范

| 表情 | 主眼与嘴形 | 使用语气 |
| --- | --- | --- |
| 标准／观察 | 上眼睑轻压，视线集中，嘴为极短平线或轻微下弧 | 默认、介绍、日常站姿 |
| 怀疑 | 一侧主眼稍窄，另一侧保持常态，嘴不张开 | 发现疑点、核实信息 |
| 思考 | 主眼视线偏向同一侧，可用一只手托下巴 | 分析、等待、推理 |
| 惊讶 | 两只主眼变圆，嘴为极小圆点 | 找到关键线索、意外发现 |
| 确认 | 眼睑轻松，嘴角仅轻微抬起 | 完成、肯定、致谢 |

副眼的数量、排列与位置保持不变，不随眉眼变形成符号。常态不加粗眉、腮红、獠牙或夸张大笑；强烈情绪也不改变基础脸型。表情图禁止额外叠加蜘蛛网来强化情绪。

## 8. 道具与动作

主要道具为圆形放大镜及小型笔记本；小红证物牌附在笔记本上。放大镜直径建议约 16H%，笔记本高约 15H%、宽约 10H%。可以只带一个道具；标准三视图不持道具。

代表动作：低头观察、持镜检查、记录线索、托腮思考、举起证物牌。动作中保持两手两脚，不因调查能力添加新肢体。允许用姿态表现机敏，避免武器、战斗姿势和英雄式肌肉造型。

## 9. 使用规范

### 完整版

用于主视觉、海报、较大贴纸和产品包装。建议数字展示高度不低于 160 px，印刷高度不低于 30 mm；这属于本版起始建议，实际应用需以小尺寸打样验证。

### 小尺寸头像版

用于头像、角标、聊天列表。采用头部正面裁切，可去掉身体、道具和帽顶蜘蛛标记，仅保留“多眼”这一识别点。副眼仍必须为六颗，不随意删减；取消副眼高光并增大到至少 2 个显示像素。建议头像不小于 48 × 48 px，小于此尺寸需单独绘制像素适配稿。

### 留白与背景

完整角色外沿至少保留 0.1H 的净空，道具纳入轮廓计算。推荐奶白或浅灰背景；深色背景需用浅色外描边或浅底容器确保轮廓清晰。场景插画可以与环境互动，但头部和主眼必须清楚。

### 单色应用

允许将主体统一转为单色，用镂空区分脸框、眼睛和服装；保留六颗副眼和蜘蛛标记的可读性。刺绣、雕刻等工艺无法呈现小细节时，应制作专用简化稿，不可直接缩放复杂稿。

### 禁止事项

- 增加实体蜘蛛腿、第三只手、尾巴或写实蜘蛛腹部。
- 在斗篷、兜帽或背景中重复铺满蜘蛛网图案。
- 改变副眼数量，或将副眼画成宝石、眉钉和随机光点。
- 把帽顶折角拉长成猫耳、兔耳；把斗篷画成蝙蝠翅膀。
- 任意替换主配色、拉长四肢、压扁头部或改变头身比例。
- 添加大嘴、尖牙、恐怖昆虫质感或明显攻击性表情。
- 在背面重复正面的蜘蛛标记，或增加其他蜘蛛装饰。

## 10. 交付与验收

本次交付：设计规范文档、标准设定视觉示意、已确认方向的概念图。设定图用于统一视觉方向，不等同于已完成逐点校正的矢量制版文件、建模工程图或商标检索结论。

后续矢量定稿建议分层：兜帽／帽顶标记／脸／主眼／副眼／斗篷／领扣／手脚／道具／轮廓／阴影。主文件建议采用 SVG 或 AI，同时导出透明 PNG 和印刷用 PDF。

验收清单：

- [ ] 正、侧、背三视图头顶与脚底对齐，头身比例一致。
- [ ] 正面为两只主眼加六颗副眼；侧面遮挡符合视角。
- [ ] 只有两只手和两只脚，无其他实体附肢。
- [ ] 蜘蛛元素不超过副眼、帽顶标记两种，背面保持素色。
- [ ] 色值符合标准色，红色面积受控。
- [ ] 主眼表达严肃、专注，整体轮廓圆润可爱。
- [ ] 头像缩小后副眼仍能分辨，蜘蛛标记不糊成色块。
- [ ] 应用稿没有大面积蛛网、花纹或多余配件。
