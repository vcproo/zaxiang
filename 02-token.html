TOKEN · 词元

Token：AI 是一块一块读字的

用 AI 的时候，你可能见过"本次消耗 1200 tokens""超出 token 上限"这种提示。这个 token 到底是什么？

先说结论

Token 就是 AI 读文字时切出来的一小块。

我们读书是一个字一个字地看。AI 不是。它先把一句话切成一块一块，每块可能是一个字，可能是一个词，也可能是半个英文单词。切出来的每一块，就叫一个 token。

打个比方：一整根甘蔗没法直接嚼，得先砍成一节一节的。Token 就是那一节一节的甘蔗。

看看 AI 眼里的一句话
每个色块是一个 token。这里是示意，真实切法每家模型都不太一样

可以看到几个特点：

  • 常见的词，比如"你好""今天"，往往一整块就切下来了。
  • 不常见的字、生僻的词，可能会被切得更碎。
  • 英文单词短的一块，长的会被拆开，比如 unbelievable 可能被拆成 un、believ、able。
  • 标点、空格也算，也占地方。

那一个汉字算几个 token？

没有固定答案，跟用的哪家模型有关。现在国内外的主流模型，大致可以按一个汉字一个 token 上下来估，有的模型更省一点，有的更费一点。英文差不多是一个单词一个多 token。

平时不用算这么细，有个大概印象就行。下面这个框可以粗略估一下：

粗略估一下
字数：0
大约 token：0
按"汉字 1 个、英文单词 1.3 个、标点 1 个"粗估，只看个数量级

为什么要知道这个东西？

因为 AI 世界里，很多事情都拿 token 当"尺子"量。

第一，收费按它算。如果你用的是按量付费的 AI 服务，价格表一般写的是"每百万 token 多少钱"。你发过去的字要算钱，它回给你的字也要算钱，通常回的那部分还更贵。就像打车，上车有起步价，跑的每一公里也算钱。

第二，能聊多长也按它算。每个 AI 一次能装下的内容有上限，这个上限也是用 token 来数的。这就是下一篇要讲的"上下文窗口"。

第三，它解释了 AI 的一些"怪毛病"。早些时候有个很出名的笑话：问 AI 英文单词 strawberry 里有几个字母 r，它经常答错。原因就在这儿，AI 看到的是 straw 和 berry 这样的块，不是一个个字母，让它数字母，有点像让你隔着包装数饼干。现在的模型在这方面已经好很多了，但这个原理还在。

几个常见的数

给你一点体感：

内容大约多少 token
一条微信消息几十个
一篇公众号文章（3000 字）三千个上下
一本 20 万字的小说二十万个上下
免费版的聊天 AI 一般不会让你直接看到 token 数，但背后是一样在算的。你会遇到"今天额度用完了""对话太长请新开一个"之类的提示，多半就是 token 用得差不多了。
记住这一句

Token 是 AI 读字的单位，大概一个汉字一个。收多少钱、能读多长，都拿它来算。
